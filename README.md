# 쉼표 (Shimpyo)

졸음쉼터에서 [쪽잠] 버튼 하나만 누르면, 공기·온도·깨우기까지 차가 알아서 챙겨 주는 쪽잠 도우미.

P단에서 쪽잠 시간(10~30분, 5분 단위, 권장 15~20분)을 정하고 시작하면 차가 바깥 공기로 바꾸고 계절에 맞는 쪽잠 온도를 맞춥니다.
쉬는 동안 내기순환으로 바뀌면 다시 바깥 공기로 되돌리고, 끝나기 3분 전부터 바람·온도·김서림 제거로 몸과 차를 먼저 깨운 뒤 음성으로 깨웁니다.
깨고 나면 "아직 피곤하신가요?"에서 연장 시간을 정해 더 쉬거나(앞서 쉰 시간과 합쳐 최대 30분) [출발]을 고르고, 출발하면 공조를 쪽잠 전 설정으로 되돌립니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 쪽잠 시간 정하기 | 10~30분 사이 5분 단위로 직접 정함 (권장 15~20분 표시) |
| 공기 지키기 | 쉬는 동안 10초마다 차 상태를 다시 읽어, 내기순환으로 바뀌면 바깥 공기로 되돌림 |
| 계절별 온도 | 바깥 온도로 여름·겨울·간절기를 판단해 온도·열선을 맞춤 |
| 단계적 깨우기 | 끝나기 3분 전부터 바람·온도·김서림 제거 → 음성 → 반응 없으면 경보 |
| 연장·출발 | 합쳐서 30분을 넘지 않게 연장, 출발하면 공조와 앱이 연 창문을 원래대로 |
| 안전 장치 | P단이 아니거나 문이 열리면 멈춤, 차가 오래 꺼졌다 켜지면 깨우지 않고 공조만 되돌림 |

## 실행 방법

1. JDK 17, Android Studio(또는 Gradle 8.10.2) 준비
2. Pleos Connect Emulator v2.1 (API 34) 실행 — Cold boot 필수(안 하면 VHAL을 쓸 수 없음)
3. 빌드·설치
   ```
   ./gradlew installDebug
   ```
4. 에뮬레이터 앱 목록에서 **쉼표** 실행

시연 모드: 준비 화면 왼쪽 위 "쉼표"를 길게 누르면 1분 = 4초(15분 쪽잠이 1분)로 줄어듭니다.
시연 모드에서 상단 차종 칩을 누르면 내연기관(디 올 뉴 아반떼) → 하이브리드(더 뉴 그랜저)로 가정해 볼 수 있습니다(에뮬레이터는 전기차 고정).

릴리스와 같은 최적화로 확인하려면: `./gradlew installStaging` (디버그 키 서명, 제출용 아님)

## 테스트 환경

- Pleos Connect Emulator v2.1.0, Android 14 (API 34), 2560×1440
- Vehicle SDK 2.3.2, TextToSpeech SDK 3.3.1
- 기어·공조·문 바꾸기: Pleos Connect Virtual Console › Emulation Controls
- 주간/야간 확인: `adb shell cmd uimode night yes` / `adb shell cmd uimode night no`
- 단위 테스트: `./gradlew testDebugUnitTest` (쪽잠 규칙·공조 계획·전체 흐름 37개)
