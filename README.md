# 쉼표 (Shimpyo)

졸음쉼터에서 [쪽잠 시작] 버튼 하나만 누르면, 자는 동안의 공기·온도와 깨우기까지 차가 알아서 챙겨 주는 Pleos Connect 쪽잠 앱입니다.

- 팀명: 눈만감았어
- 패키지: `com.shimpyo.app` · 버전 1.0.0
- APK: `apk/눈만감았어_쉼표_release.apk`

## 앱 소개

1. **시작**: 차를 P단에 두고 쉴 시간을 정한 뒤 [쪽잠 시작]을 누릅니다. 시간은 10분에서 30분 사이를 1분 단위로 고르고, 15–20분은 권장 시간으로 표시됩니다.
2. **쉬는 동안**: 차가 바깥 공기와 약한 바람으로 바꾸고 계절에 맞는 온도를 맞춥니다. 10초마다 차 상태를 다시 읽어, 내기순환으로 바뀌었거나 온도·바람이 달라졌으면 원래대로 되돌립니다.
3. **깨우기**: 끝나기 3분 전부터 바람·온도·앞유리 김서림 제거·뒷유리 열선으로 몸과 차를 먼저 깨우고, 시간이 되면 알림음과 음성으로 깨웁니다.
4. **출발 전 확인**: "아직 피곤하신가요?"에서 더 쉬거나 출발을 고릅니다. 출발하면 공조가 쪽잠 전 설정으로 돌아갑니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 쪽잠 시간 정하기 | 10분에서 30분 사이를 1분 단위로 정함. [−]/[+]를 누르고 있으면 빠르게 넘어감. 15–20분은 '권장 시간', 25분 이상은 깬 뒤 멍할 수 있다는 안내 표시 |
| 바깥 공기 유지 | 외기로 바꾸고 바람 2단 유지. 내기순환으로 바뀌면 바로 되돌리고, 10초마다 다시 읽어 확인. 외기 제어가 안 되는 차는 운전석 창문을 가장 작은 단계(1–2cm)로 열고, 둘 다 안 되면 시작하지 않음 |
| 계절별 온도 | 바깥 온도로 계절 판단 (24℃ 이상 여름, 12℃ 이하 겨울, 그 사이 간절기). 여름 24℃ + 에어컨, 간절기 23℃, 겨울 22℃ + 운전석 열선. 듀얼 공조 차는 동승석도 같이 맞춤 |
| 단계적 깨우기 | 끝나기 3분 전 바람 4단, 앞유리 김서림 제거, 뒷유리 열선, 온도 조정(겨울엔 핸들 열선). 시간이 되면 알림음 → 음성, 반응이 없으면 30초마다 소리를 키워 반복하고 6번째에는 경보 화면과 최대 바람 |
| 쪽잠 상태 화면 | 남은 시간, 구간 타임라인, 차에서 다시 읽은 값(바깥 공기 유지 횟수, 온도, 바람, P단·문·경고)을 측정·설정·예정으로 구분해 표시. [화면 어둡게], [지금 깨기] 버튼 |
| 연장·출발 | 연장은 1분 단위(최소 5분)로 여러 번 가능하지만 앞서 쉰 시간과 합쳐 30분까지. 출발하면 바뀐 공조와 앱이 연 창문을 쪽잠 전 상태로 되돌리고, 한 번 더 읽어 덜 돌아간 값은 다시 보냄 |
| 안전 장치 | P단·정차일 때만 시작. 쉬는 중 기어가 P에서 벗어나면 바로 끝내고 공조 복원. 운전석 문이 열리면 깬 것으로 보고 확인 화면으로. 전원 차단 경고, 공조가 계속 꺼짐(시동 꺼짐)일 때 깨움. 차가 꺼졌다 켜지면 이어서 깨우고, 깨울 시각이 30분 넘게 지났으면 깨우지 않고 공조·창문만 되돌림 |
| 차종별 안내 | 연료 종류를 읽어 내연기관(배기구 앞 확인), 하이브리드(스테이 모드 안내), 전기차별로 시작 전 확인 사항을 보여 줌 |

서버, 로그인, 외부 인터넷 API를 쓰지 않으며 모든 동작이 차 안에서 오프라인으로 이루어집니다.

## 실행 방법

### 1. 에뮬레이터 켜기

Pleos Connect Emulator v2.1 (API 34)를 **처음부터 부팅(Cold Boot)** 되게 켭니다. 아래 방법 중 아무거나 쓰면 됩니다.

| 방법 | 설명 |
|---|---|
| Device Manager ▶ | 에뮬레이터의 Boot option이 **Cold boot**이면 ▶만 누르면 됩니다. 설정: Device Manager › 에뮬레이터 ⋮ › Edit › Show Advanced Settings › Boot option = Cold boot |
| Device Manager ⋮ › Cold Boot Now | 설정을 바꾸지 않고 이번 한 번만 처음부터 켭니다 |
| Android Studio ▶ Run | 실행 대상으로 Pleos Connect Emulator를 고르고 Run. 부팅 방식은 Boot option 설정을 따릅니다 |
| 명령어 | `emulator -avd <AVD 이름> -no-snapshot-load` |

> Boot option이 Quick boot이면 저장해 둔 상태에서 이어 켜지는데, 이때는 가상 차량(VHAL)과의 연결이 다시 맺어지지 않아 공조·기어 같은 차량 값을 읽거나 바꿀 수 없습니다. 차량 값이 바뀌지 않으면 Cold Boot Now로 다시 켜 주세요.

### 2. 차 전원 켜기

Virtual Console › Power System을 **On**으로 바꿉니다. 차 전원이 꺼져 있으면 공조 제어가 거부됩니다.

### 3. APK 설치

둘 중 하나를 쓰면 됩니다.

- `apk/눈만감았어_쉼표_release.apk`를 내려받아 에뮬레이터 화면에 **끌어다 놓기**
- 또는 `adb install apk/눈만감았어_쉼표_release.apk`

설치 후 하단바 앱 목록(⊞)에서 **쉼표**(주황 배경의 흰 쉼표 아이콘)를 실행합니다.

### 4. 빠르게 확인해 보기 (약 1분)

1. 준비 화면 왼쪽 위 **"쉼표"를 길게 눌러** 시연 모드를 켭니다. 1분이 3초로 줄어들어 15분 쪽잠이 45초에 끝납니다. 다시 길게 누르면 꺼집니다.
2. 기어가 P인지 확인하고 [쪽잠 시작]을 누릅니다.
3. Virtual Console에서 내기순환(Recirculation)을 켜 보면, 앱이 바로 바깥 공기로 되돌리고 화면에 기록을 남깁니다.
4. 끝나기 3분 전(시연 모드에서는 9초 전)에 바람·온도·김서림 제거가 바뀌고, 시간이 되면 깨우기 화면이 나옵니다.
5. [일어났어요] → "아직 피곤하신가요?"에서 연장하거나 [괜찮아요 · 출발]을 누르면 공조가 쪽잠 전 설정으로 돌아갑니다.

시연 모드에서는 상단 차종 칩을 눌러 내연기관(디 올 뉴 아반떼)이나 하이브리드(더 뉴 그랜저)로 가정해 볼 수 있습니다. 에뮬레이터 차량은 전기차(IONIQ 5)로 고정되어 있습니다. release 빌드는 실제 시간으로 시작하고, 디버그 빌드는 처음부터 시연 모드로 시작합니다.

### 소스에서 빌드

- JDK 17, Android Studio (Gradle 8.10.2)
- 디버그 빌드 설치: `./gradlew installDebug`
- release 빌드는 `local.properties`에 서명 정보(`SHIMPYO_KEYSTORE` 등)가 있어야 서명됩니다. 서명 키는 저장소에 넣지 않습니다.

## 테스트 환경

- Pleos Connect Emulator v2.1.0, Android 14 (API 34), 화면 2560×1440
- Pleos Vehicle SDK 2.3.2, Pleos TextToSpeech SDK 3.3.1
- 기어·공조·문 바꾸기: Pleos Connect Virtual Console › Emulation Controls
- 주간/야간 테마 확인: `adb shell cmd uimode night yes` / `adb shell cmd uimode night no`
- 단위 테스트: `./gradlew testDebugUnitTest` (쪽잠 규칙, 공조 계획, 김서림, 시동 꺼짐, 전체 흐름 등 50개)
